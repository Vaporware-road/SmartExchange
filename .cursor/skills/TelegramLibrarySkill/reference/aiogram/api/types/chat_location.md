# ChatLocation

> Source: [https://docs.aiogram.dev/en/latest/api/types/chat_location.html](https://docs.aiogram.dev/en/latest/api/types/chat_location.html)

*class* aiogram.types.chat_location.ChatLocation(*\**, *location: [Location](location.html#aiogram.types.location.Location "aiogram.types.location.Location")*, *address: str*, *\*\*extra_data: Any*)
:   Represents a location to which a chat is connected.

    Source: <https://core.telegram.org/bots/api#chatlocation>

    location*: [Location](location.html#aiogram.types.location.Location "aiogram.types.location.Location")*
    :   The location to which the supergroup is connected. Can’t be a live location

    address*: str*
    :   Location address; 1-64 characters, as defined by the chat owner
