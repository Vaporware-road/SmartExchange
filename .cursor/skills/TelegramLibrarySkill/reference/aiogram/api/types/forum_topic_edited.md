# ForumTopicEdited

> Source: [https://docs.aiogram.dev/en/latest/api/types/forum_topic_edited.html](https://docs.aiogram.dev/en/latest/api/types/forum_topic_edited.html)

*class* aiogram.types.forum_topic_edited.ForumTopicEdited(*\**, *name: str | None = None*, *icon_custom_emoji_id: str | None = None*, *\*\*extra_data: Any*)
:   This object represents a service message about an edited forum topic.

    Source: <https://core.telegram.org/bots/api#forumtopicedited>

    name*: str | None*
    :   *Optional*. New name of the topic, if it was edited

    icon_custom_emoji_id*: str | None*
    :   *Optional*. New identifier of the custom emoji shown as the topic icon, if it was edited; an empty string if the icon was removed
